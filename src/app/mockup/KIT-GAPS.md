# Kit-member gaps found by the design mockups

Composed page-locally in the mockups that stood under this directory; each was
flagged for real kit work in `packages/ui` (intent block, every state, showcase
specimen) to be done before the surfaces it served were built. Nothing here was
added to the kit in the mockup session.

**Every gap this document opened is now closed** — as of Slice 5 (2026-07-26),
each row below is either a shipped kit member or a recorded decision not to
build one. The mockups themselves are gone: the last of them,
`admin-questions/`, was deleted with the slice that ported it. What remains in
this directory besides this file is `page.tsx` + `mockup-harness.tsx`, which are
the permanent `FakeMatchClient` dev harness rather than a design mockup — see
their header comments. This file stays as the record of what the mockups
taught the kit; new gaps belong to whatever surface finds them.

Non-kit findings for the builders:

- The lobby marked the leader with the word "leader" — the markers-are-icons
  law wants an icon (the mockups use ★ with an accessible name). **Resolved:**
  the roster now marks the leader with ★ carrying an accessible name, in the
  team room the lobby collapsed into (Slice 3).
- The home join form reported a bad code without the rejection shake; UI.md
  names the shake as the form-error affordance (the `home/` mockup shows it).
  **Resolved:** the join card plays `SLIP_SHAKE` on a rejected code (Slice 1).
- `ConfirmDialog` had no failure state, so a surface adopting it lost its
  delete-error path. **Resolved:** it gained an `error?: string` state in
  Slice 5 — a retryable dialog rather than one that dismisses on failure.
- The trivia `Rope` is a game-surface indicator, not a kit member (game
  surfaces design their own indicators against the status vocabulary per
  UI.md); it should ship with the trivia surface, intent-documented there.
  **Resolved as planned:** it shipped at `src/components/minigames/trivia/Rope.tsx`
  in Slice 4, carrying its intent comment, and stayed out of the kit.
